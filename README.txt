NOCTURNE FREE 0.7

Dies ist ein Offline-Prototyp ohne KI-Anbindung und ohne Kosten.

Zum lokalen Testen: index.html im Browser öffnen.

Für iPhone-Installation: Alle Dateien gemeinsam auf einen HTTPS-Webhost hochladen. Dann die URL in Safari öffnen > Teilen > Zum Home-Bildschirm.

WICHTIG: Charaktere im Browser exportieren, bevor du den Speicher löschst. Browserdaten werden nicht automatisch zwischen PC und iPhone synchronisiert.

Keine API-Schlüssel im Frontend speichern. Ein späterer Cloud-KI-Dienst benötigt einen sicheren Server und Prüfung der Inhaltsregeln.
